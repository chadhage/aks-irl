The brief

The scenario in one paragraph

Skybridge Messaging Services runs a real-time airline communications bus over persistent TCP sockets: a Java socket gateway holding long-lived connections to airline endpoints (DCS, baggage, flight ops, GDS), a C/C++ message parser that decodes the wire format and applies routing rules, and a PostgreSQL store for routing tables, journals, and end-of-day reconciliation. Today it runs on RHEL VMs, scaled vertically, patched in place, and failed over by hand.

The board approved a 12-month modernization. This workshop builds the MVP — the first vertical slice that proves the architecture on Azure against realistic load, sufficient to onboard one airline partner for a controlled pilot.

Pain the board signed off on

  • 01 Patch fragility — 3 self-inflicted outages in 18 months
  • 02 Bi-modal capacity — ~$1.8M/yr of idle peak-sized compute
  • 03 No safe A/B — parser changes ship without a staged rollout
  • 04 DR unproven — 90+ min RTO, last drilled in 2022
  • 05 Talent risk — 2 of 3 C/C++ maintainers retire in 2027

Design moves the workshop defends

Containerize first, refactor later

The Java gateway and C++ parser ship in containers with no source rewrite — gaining autoscale, GitOps, and zone-survival without a rewrite.

Private API · CNI Overlay · 3 zones · Istio

Connection-oriented workloads stay off a public API server. Overlay scales sockets without VNet exhaustion; Istio adds mTLS and ring-routing.

StatefulSet gateway, sticky by socket

Long-lived TCP behaves poorly behind a rolling Deployment. Stable identities and sticky routing avoid reconnect storms on every push.

Managed PostgreSQL, not in-cluster

State stays out of the cluster. Managed HA, PITR, and geo-replication with an Azure SLA fit this workload better than a self-managed StatefulSet.

A/B by parser, not gateway

The gateway holds socket state; the parser is stateless per message. A/B parser-cpp:v1 vs v2 by Istio header match — sockets never move.

Rings with a human gate

dev → canary → prod, with canary soak and a required PR review plus a manual Argo sync before prod. Every change is traceable.
